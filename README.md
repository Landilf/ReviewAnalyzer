# ReviewAnalyzer — Платформа для интеллектуального анализа отзывов

**ReviewAnalyzer** — это комплексное решение для автоматизированного сбора, глубокого анализа и визуализации отзывов потребителей. Проект сочетает в себе современные методы машинного обучения (NLP), веб-парсинг и интерактивную бизнес-аналитику. 

Проект разработан в рамках преддипломной практики студента 4 курса (РГРТУ, каф. ВПМ).

## 🌟 Основные возможности

### 1. Сбор данных (Scraping)
*   **Специализированные парсеры:** Глубокая интеграция с `Otzovik.com` и `DNS-shop.ru` для обхода защиты и корректного извлечения данных.
*   **Универсальный парсер:** Эвристический алгоритм для извлечения отзывов с произвольных сайтов.
*   **Два режима загрузки:**
    *   `HTTP (Requests)` — для быстрой загрузки простых страниц.
    *   `Browser (Playwright)` — для динамических сайтов с JavaScript и защитой от ботов.
*   **Поддержка локальных файлов:** Импорт данных в форматах `CSV` и `Excel`.

### 2. Интеллектуальный анализ (NLP Pipeline)
*   **Анализ тональности (Sentiment Analysis):**
    *   **Основной рабочий контур (Transformer):** Использование предобученной нейросети `cointegrated/rubert-tiny-sentiment-balanced` для высокоточного контекстного анализа русскоязычных текстов.
    *   **Экспериментальный контур (Классический ML):** Метод `TF-IDF + Logistic Regression`, доступный в панели разработчика для дообучения модели под конкретную предметную область (доменная адаптация) на пользовательской выборке.
*   **Извлечение аспектов (Aspect Extraction):**
    *   Автоматическое выделение характеристик товара (например, "цена", "качество сборки", "аккумулятор").
    *   Лёгкий правиловой метод (без тяжёлых лингвистических зависимостей).
*   **Тематическое моделирование (LDA):** Автоматическое группирование отзывов по скрытым темам на основе статистического распределения слов (алгоритм Latent Dirichlet Allocation).
*   **Кластеризация (K-Means):** Группировка похожих по смыслу отзывов с использованием `KMeans` и `TF-IDF` признаков для выявления типовых сценариев использования и повторяющихся проблем.

### 3. Визуализация и Dashboards
*   **Краткий обзор:** Главные тезисы, интегральная оценка и автоматические рекомендации.
*   **Расширенная аналитика:**
    *   Динамика отзывов во времени.
    *   Матрица аспектов (выявление "болевых точек" продукта).
    *   Облака слов (Word Clouds) для разных типов тональности.
    *   Интерактивные диаграммы распределения тем и кластеров.
*   **Анализ качества:** Оценка точности моделей при наличии истинных меток, матрица ошибок (Confusion Matrix) и сравнение алгоритмов.

## 📂 Структура проекта

Архитектура системы построена на базе слабо связанных модулей:

```text
ReviewAnalyzer/
├── streamlit_app.py          # Главный файл запуска (оркестрация и UI)
├── analysis_helpers/         # Ядро анализа (NLP и Pipeline)
│   ├── aspects.py            # Логика извлечения аспектов
│   ├── sentiment.py          # Модели анализа тональности
│   ├── topics.py             # Тематическое моделирование (LDA)
│   └── pipeline.py           # Основной конвейер обработки данных
├── review_parser/            # Модули сбора данных
│   ├── service.py            # Фасад для управления парсерами
│   ├── otzovik_crawler.py    # Специфичный парсер для Otzovik
│   ├── dns_crawler.py        # Специфичный парсер для DNS
│   └── browser_loader.py     # Интеграция с Playwright
├── ui/                       # Компоненты интерфейса
│   └── dashboard/            # Страницы и виджеты дашборда
├── utils/                    # Вспомогательные утилиты
├── requirements.txt          # Зависимости проекта
└── app_logger.py             # Инфраструктура централизованного логирования
```

## 🚀 Быстрый старт

### 1. Требования
Убедитесь, что у вас установлен Python 3.9 или выше.

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка парсера (Playwright)
Для работы функции загрузки по ссылке с динамических сайтов:
```bash
playwright install chromium
```

### 4. Запуск приложения
```bash
streamlit run streamlit_app.py
```

## 📊 Формат входных данных (CSV/Excel)

Приложение автоматически определяет нужные столбцы, но для лучшего результата рекомендуется:
*   `text` (обязательно) — текст отзыва.
*   `label` (опционально) — разметка (positive, neutral, negative) для оценки качества классификации.
*   `date` (опционально) — дата написания.
*   `rating` (опционально) — оценка (1-5).

## 💡 Использование в учебных целях (Защита ВКР/практики)

Для демонстрации работы рекомендуется следующий сценарий:
1.  **Сбор данных:** Вставьте ссылку на товар с `Otzovik` или `DNS` в разделе "Загрузка по ссылке".
2.  **Анализ аспектов:** Покажите вкладку "Исследование" -> "Аспекты", чтобы увидеть, на что чаще всего жалуются пользователи.
3.  **Глубокий поиск:** Отфильтруйте отзывы по конкретному негативному аспекту и покажите исходные тексты во вкладке "Отзывы".
4.  **Сравнение моделей / Дообучение:** В панели разработчика (включается в настройках) продемонстрируйте возможность экспериментального дообучения модели `TF-IDF + Logistic Regression` на пользовательском наборе данных для адаптации под предметную область.
5.  **Экспорт:** Сохраните итоговый отчет в формате HTML или выгрузите отфильтрованную таблицу в CSV для внешних систем аналитики.
