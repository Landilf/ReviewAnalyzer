# ReviewAnalyzer

Проект для анализа и визуализации пользовательских отзывов: определение тональности, извлечение аспектов, тематическое моделирование, интерактивная фильтрация и экспорт результатов.

## Возможности

- загрузка отзывов из `CSV` или `Excel`;
- загрузка отзывов по ссылке на страницу товара, если сайт отдаёт отзывы в HTML или встроенных данных страницы;
- анализ тональности классической моделью `TF-IDF + Logistic Regression` или transformer-моделью RuBERT;
- извлечение аспектов отзывов простым методом или через `spaCy`;
- интерактивные графики распределения тональности, динамики отзывов и проблемных аспектов;
- автоматические выводы и рекомендации по результатам анализа;
- сравнение периодов, drill-down по аспектам и темам;
- облака слов для позитивных, нейтральных и негативных отзывов;
- матрица ошибок и сравнение моделей;
- кластеризация похожих отзывов;
- предметный словарь важных аспектов;
- тематическое моделирование `LDA` с ключевыми словами тем;
- фильтрация по тональности, категории, уверенности модели и ключевым словам;
- экспорт полного или отфильтрованного результата в `CSV`, а также HTML-отчёта.

## Интерфейс

Приложение разделено на 2 основных режима:

- `Краткий обзор` — главные тезисы, интегральная оценка товара, ключевые рекомендации;
- `Расширенный анализ` — вкладки для аналитики:
  - `Исследование` (аспекты, темы, кластеры, периоды, облака слов),
  - `Отзывы` (таблицы и экспорт),
  - `Качество` (метрики и сравнение моделей),
  - `Отчёт` (предметный словарь и HTML-выгрузка).

Функции `Загрузка по ссылке` и `Для разработчика` доступны в расширенном режиме как вспомогательные инструменты, чтобы не перегружать основной UX. Панель разработчика скрыта по умолчанию и включается флажком `Показать инструменты разработчика` в дополнительных настройках.

Код интерфейса разнесён по модулям в `ui/dashboard/`, чтобы приложение было проще расширять.

## Формат данных

Минимально нужен столбец:

- `text` — текст отзыва.

Дополнительные столбцы:

- `label` — истинная тональность: `positive`, `neutral`, `negative`;
- `date` — дата отзыва;
- `category` — категория товара или услуги;
- `rating` — пользовательская оценка.

Если дополнительных столбцов нет, приложение создаст служебные значения автоматически.

## Запуск

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Для импорта по ссылке нужны доступ к интернету и сайт, который не скрывает отзывы за закрытым API или антибот-защитой. Лучше всего подходят текстовые сайты с открытыми HTML-отзывами, например `otzovik.com`.
Если включена браузерная загрузка, после установки зависимостей также выполните:

```bash
playwright install chromium
```

На NixOS можно использовать системный Chromium вместо браузера Playwright:

```bash
export PLAYWRIGHT_CHROMIUM_EXECUTABLE=/run/current-system/sw/bin/chromium
streamlit run streamlit_app.py
```

Важно: запуск `python streamlit_app.py` не подходит для Streamlit-приложений.

## Идея для защиты

На демонстрации удобно показать сценарий: загрузить отзывы, отфильтровать негативные, найти проблемный аспект, открыть исходные отзывы и экспортировать результат для дальнейшей работы.
