# Набор данных для ABSA

Здесь будут храниться размеченные пары «отзыв — аспект — тональность аспекта».

- `train/` — выборка для обучения модели;
- `validation/` — выборка для настройки модели и выбора гиперпараметров;
- `test/` — отложенная выборка для финальной независимой оценки качества.

Один исходный CSV обрабатывается за раз. После ручной проверки разметки записи будут распределяться между выборками без пересечений по `review_id`.

Исходные файлы в `data/csv/` не изменяются.
