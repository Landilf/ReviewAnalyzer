# Набор данных для ABSA

Здесь будут храниться размеченные пары «отзыв — аспект — тональность аспекта».

- `train/` — выборка для обучения модели;
- `validation/` — фиксированная выборка для выбора лучшей эпохи;
- `test/` — отложенная выборка для единственной финальной независимой оценки лучшей эпохи.

Разделение выполняется по отзывам, а не отдельным аспектам: один отзыв не может попасть более чем в одну выборку. Для объединённых `validation_absa.csv` и `test_absa.csv` сохраняется столбец `source_dataset`, поэтому совпадающие `review_id` из разных исходных файлов не смешиваются.

При новом запуске обучения Streamlit автоматически использует все CSV из `validation/` и `test/`. Метрики на validation показываются для каждой эпохи, а `test_metrics.json` создаётся только после выбора лучшей эпохи.

Исходные файлы в `data/csv/` не изменяются.
